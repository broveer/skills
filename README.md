# AI Skills Repository

This repository is to make skills for things that don't have skills but can be useful for many AI models to have. The goal is to provide comprehensive, well-documented skills that help models write better code and provide better assistance for specialized topics.

## Current Skills

- **charm-hyper**: A skill to help models implement AI models from Hyper (by Charm) into any project easily. Includes code examples for cURL, Python, Node.js, and Go.
